# QR Code Studio

A single-page QR code generator. Enter a URL or text, adjust the colors, PNG size, and error correction level, then download the result. Generation happens in the browser.

The site is static: open `dist/index.html` in a browser or serve the `dist` directory with any static HTTP server.

The bundled `dist/qrcode.js` is [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 2.0.4, licensed under MIT. Its license notice is included in the source file.
